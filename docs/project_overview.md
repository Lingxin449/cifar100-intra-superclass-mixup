## 1. 一句话概述

标准 Mixup 与层次化监督在标签层面互斥：超类标签是离散类别，不能按 λ 插值。把第二张图的抽取范围限制在同一超类内，这个冲突消失；六组对照实验显示，这条配对规则在 Mixup 与 CutMix 上复现出同一种效应——准确率下降约 0.65pp，超类内错占比上升约 1.5–1.7pp。

---

## 2. 背景

CIFAR-100 有 100 个细类，按语义归入 20 个超类，每个超类恰好 5 个细类。数据集目录天然给出两级标签，因此可以同时训练细类头和超类辅助头。

Mixup 是一种常用的数据增强：从 batch 里随机取两张图，按 λ 做像素级线性插值，标签也按同一 λ 混合。它的问题在于配对完全随机，与类别层级无关。

本项目要回答的问题不是"能不能把准确率刷高"，而是：

> 当模型同时接受超类监督时，Mixup 的随机配对是否仍然成立？如果不成立，改动配对规则会带来什么可测量的后果？

---

## 3. 问题的发现

### 3.1 理论概率

每个超类有 5 个细类。随机抽两张图，落在同一超类的概率为：

```
20 × (5/100)² = 0.05
```

即 95% 的配对跨越超类。

### 3.2 按训练集分布计算

在完整训练集（50000 张，每个超类 2500 张）上按真实类别分布计算，同超类配对概率为 **0.0500**（20 × (2500/50000)² = 0.05），跨超类 **95.0%**，与理论值一致。抽到的真实样本包括"盘子 × 鲨鱼""婴儿 × 玫瑰""城堡 × 鲸"。

### 3.3 为什么这是问题

细类标签可以插值，因为它描述"这张图有多大比例像玫瑰"。超类标签描述的是"属于哪一族"，是离散归属。混合后的粗标签：

```
0.5 × 花卉 + 0.5 × 鱼类 = ?
```

不对应任何一个合法超类。模型被要求拟合一个不存在的类别，超类损失的梯度方向无意义。

---

## 4. 方法

### 4.1 核心改动

配对仍然随机，但第二张图只在**同一超类内部**抽取：

```
x̃ = λ·x_i + (1−λ)·x_j,    j ∈ {k | c_k = c_i}
ỹ_fine  = λ·y_i + (1−λ)·y_j      （细类照常插值）
ỹ_coarse = c_i                    （超类标签严格不变）
```

实现上只替换配对索引的生成方式（组内循环置换，不会自配），模型、损失、增强、超参全部沿用。

### 4.2 代码级保证

```python
if rule == "intra":
    # 同超类配对后超类标签严格不变
    assert (yctr[perm] == yctr[idx]).all(), "intra 配对破坏超类标签不变性"
```

这条性质写在断言里，不靠口头声称。

### 4.3 CutMix 形态

同一配对原则换成 CutMix 算子：从 B 中抠一块矩形贴到 A 上，λ 按**实际贴块面积**重算；贴块左上角限定在"能完整放进图内"的范围，避免边界裁剪导致实际混合强度系统性偏低（实测 λ=0.5 时面积只剩 0.278）。

### 4.4 损失

```
L = L_fine(x̃, ỹ_fine) + 0.3 · L_coarse(x̃, ỹ_coarse)
```

细类与超类都按 λ 线性插值，标签平滑 0.1。

## 5. 实验设计

### 5.1 六组对照

| 组 | 混合算子 | 配对规则 | 超类辅助头 | 作用 |
|---|---|---|---|---|
| base | 无 | — | 无 | 对照起点 |
| hier | 无 | — | 有 | 只增加超类头 |
| mix_std | Mixup | 全批随机 | 有 | 超类标签被迫插值 |
| mix_intra | Mixup | 超类内 | 有 | 超类标签保持不变 |
| cutmix_std | CutMix | 全批随机 | 有 | 同一原则的第二次检验 |
| cutmix_intra | CutMix | 超类内 | 有 | 超类标签保持不变 |

两条阶梯结构完全平行，阶梯内部唯一变量是配对规则，阶梯之间唯一变量是混合算子。

### 5.2 控制变量

网络结构、参数量、训练轮数、优化器、学习率调度、权重衰减、标签平滑、数据增强、λ 采样分布、超类损失权重、随机种子全部相同。

### 5.3 训练配置

| 项目 | 取值 |
|---|---|
| 训练轮数 | 120 |
| 批大小 | 128 |
| 优化器 | SGD + Nesterov 动量 0.9 |
| 学习率 | 0.1，5 轮线性 warmup 后余弦退火 |
| 权重衰减 | 5e-4 |
| 标签平滑 | 0.1 |
| Mixup 概率 / α | 0.5 / 1.0 |
| 超类损失权重 | 0.3 |
| 随机种子 | 42 |

### 5.4 评估指标

- 细类 Top-1 / Top-5
- 超类准确率（辅助头输出、由细类概率诱导两种口径）
- **超类内混淆率**：细类判错的样本中，预测类别仍与真值同超类的比例
- **跨超类错误数**：预测类别落在其他超类的样本数

## 6. 实现要点

### 6.1 模型

自搭 CIFAR 风格 ResNet，针对 32×32 输入去掉 ImageNet 版的 7×7 大卷积与初始 maxpool，三个 stage 宽度 64/128/256、每 stage 2 个残差块。

| 指标 | 数值 |
|---|---|
| 可训练参数（含超类头） | 2,805,944 |
| 主干参数 | 2,800,804 |
| 超类头 | 5,140（占 0.18%） |
| 单张 32×32 输入 MACs | 421.2M |

### 6.2 数据管线

增强用 numpy 手写：reflect-pad 4 → 随机裁剪 32 → 随机水平翻转 → Cutout 8。不依赖 torchvision，避免版本差异，云端与本地行为一致。

### 6.3 工程

- 每个 epoch 评估并写 checkpoint，支持断点续训
- torch 与 Paddle 双后端，共用数据、增强、配对、评估与绘图代码，仅模型/损失/训练循环切换；两版参数量与基线数字完全一致
- 数据路径自动适配本地、AutoDL、AI Studio、Kaggle、Colab
- 六组 720 轮在 Tesla V100-32GB 上端到端约 4.5 小时，显存占用约 1.5GB

## 7. 结果

### 7.1 主结果（末轮，10000 张测试图）

| 组 | Top-1 | Top-5 | 诱导超类准确率 | 超类内错占比 | 跨超类错误 |
|---|---|---|---|---|---|
| 随机森林（HOG + 颜色直方图） | 0.2823 | 0.5251 | — | 15.05% | — |
| base | 0.7723 | 0.9337 | 85.79% | 35.18% | 1476 |
| hier | 0.7763 | 0.9359 | 86.61% | 37.73% | 1393 |
| mix_std | 0.7891 | 0.9501 | 87.38% | 38.83% | 1290 |
| mix_intra | 0.7827 | 0.9448 | 87.09% | 40.31% | 1297 |
| cutmix_std | **0.7932** | 0.9464 | **88.07%** | 40.62% | **1228** |
| cutmix_intra | 0.7863 | 0.9461 | 87.78% | **42.30%** | 1233 |

### 7.2 阶梯内对照（真正的因果比较）

| 阶梯 | 准确率 | 超类内错占比 | 跨超类错误 | 超类准确率 |
|---|---|---|---|---|
| Mixup：超类内 − 标准 | −0.64pp | +1.48pp | +7 张 | −0.29pp |
| CutMix：超类内 − 标准 | −0.69pp | +1.68pp | +5 张 | −0.29pp |

两条阶梯方向相同、幅度几乎相同。**这是"配对原则与混合算子无关"的直接证据。**

### 7.3 误差构成

以 CutMix 阶梯为例：标准配对总错 2068 张（跨类 1228、类内 840），超类内配对总错 2137 张（跨类 1233、类内 904）。多出来的 69 张错误里，64 张落在超类内部，跨类只多 5 张。

### 7.4 四种统计口径

| 口径 | Mixup 标准 / 超类内 | 差 | CutMix 标准 / 超类内 | 差 |
|---|---|---|---|---|
| 末轮 | 0.7891 / 0.7827 | 0.64pp | 0.7932 / 0.7863 | 0.69pp |
| 末 5 轮均值 | 0.7876 / 0.7833 | 0.43pp | 0.7922 / 0.7850 | 0.72pp |
| 末 10 轮均值 | 0.7858 / 0.7827 | 0.31pp | 0.7910 / 0.7840 | 0.70pp |
| 末 20 轮均值 | 0.7795 / 0.7765 | 0.30pp | 0.7858 / 0.7792 | 0.66pp |

方向在八种组合中全部一致。

## 8. 结论与解释

### 8.1 三个假设的检验

| 假设 | 内容 | 结果 |
|---|---|---|
| H1（强） | 病态超类标签会损害训练，超类内配对应更准 | **被否证**，两条阶梯都低 0.6–0.7pp |
| H2（弱） | 超类内配对会让错误更多落在超类内部 | **被复现**，+1.48 / +1.68pp |
| H3 | 该配对原则与混合算子无关 | **成立**，CutMix 上同号同量级 |

### 8.2 为什么强假设会失败

1. 标准 Mixup 的粗标签是 0.5λ 的软混合，模型可以把它当作软目标吸收，实际危害小于理论推测。
2. 超类损失权重只有 0.3，且 20 类任务本身容易，各组超类准确率都在 86%–88%。
3. 超类内配对把候选从 100 类缩到 5 类，配对多样性下降约 20 倍，这部分损失超过了标签一致性带来的收益。

### 8.3 可复现的结论

> 超类内配对确实消除了标签冲突，并在两种混合算子上复现出同一种错误结构变化；但它付出了约 0.65pp 的准确率，且没有提升超类准确率。标签冲突真实存在，却不是准确率的瓶颈；配对多样性才是主导因素。

## 9. 局限性

- **单一随机种子**（42），未做多种子重复，没有误差棒；跨种子方差未知。
- **效应量小**：0.65pp 约等于 65 张测试图。
- 超类内配对**缩小配对多样性**，对 batch size 比标准 Mixup 更敏感。
- 依赖**已知层次标签**；真实场景需要先聚类出层次。
- 仅在 CIFAR-100、32×32、120 轮、单卡条件下验证。
