## 全片叙事一句话

**标准 Mixup 与层次化监督在数学上互斥；把配对限制在同一超类内，两者可以同时生效——代价是 0.31 个百分点的准确率，收益是错误更多落在同一超类内。**

叙事弧：**数据 → 观察 → 机制 → 解法 → 代价 → 实验 → 裁决 → 边界 → 结论**

## 预判提问（1 分钟问答）

| 提问 | 回答要点 |
|---|---|
| 准确率提升了吗？ | 没有，四组在噪声量级内并列；改变的是错误结构。 |
| 为什么不调参把准确率提高？ | 只调本方案会破坏“唯一变量”；四组一起调则对比结论不变。 |
| 只有一个随机种子？ | 是，已知局限；已量化组内波动 0.29pp，多种子重复是下一步。 |
| 为什么不用 CutMix？ | 同一配对原则的 CutMix 版本已实现，正在跑，用于检验该原则是否与算子无关。 |
| 超类标签哪来的？ | 数据集目录结构自带；真实场景需先聚类出层次，这是自然扩展。 |
| 和已有层次 Mixup 工作有何不同？ | 不主张首创方法，主张一条可证伪的机制解释 + 严格对照实验。 |
